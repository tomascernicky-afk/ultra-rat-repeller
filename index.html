Technické specifikace & Ultrazvuková fyzika

1. Princip 22 000 – 25 000 Hz

Potkani (Rattus norvegicus) a krysy vnímají zvuky v rozsahu 200 Hz až 80–90 kHz. Pásmo 22–25 kHz je pro lidi neslyšitelné, ale pro hlodavce představuje oblast varovných sociálních vokalizací a akustického diskomfortu.

2. Anti-Habituation Engine

Běžné statické ultrazvukové odpuzovače selhávají do 3–7 dnů, protože si hlodavci na neměnný tón zvyknou (habituace). Tento engine využívá procedurální stochastické algoritmy, proměnlivé sweeps, rapidní pulzy a náhodné periody klidu, čímž habituaci znemožňuje.

3. Akustická realita reproduktorů

Software generuje matematicky přesnou sinusovou / FM vlnu prostřednictvím Web Audio API s využitím 32-bit floating point syntézy a nulových artefaktů (soft de-clicking envelope). Přesto běžné dynamické membrány telefonů nemohou fyzicky kmitat na 24 kHz se silným akustickým tlakem. Pro seriózní nasazení použijte audio výstup zapojený do ultrazvukového piezo měniče.
